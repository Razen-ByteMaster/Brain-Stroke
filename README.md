## ✨ What is this?

A tabular-ML classifier that estimates stroke risk from routine patient data (age, glucose, BMI, hypertension, heart disease, smoking, work type…). Preprocessing, SMOTE oversampling, and the classifier live inside one leak-proof pipeline — one artifact, no train/serve skew.

| Capability | Details |
|---|---|
| 🏆 Tuned model | RandomForest, 40-iteration randomized search on ROC AUC (5-fold stratified CV) |
| ⚖️ Imbalance handling | SMOTE inside the pipeline + `class_weight` in the search space (~5% positives) |
| 🧹 Leak-proof pipeline | Median/mode imputation → scaling/one-hot → SMOTE → classifier, all in one object |
| 🚀 API | `POST /predict` (typed schema, `residence_type` alias) + `GET /` health check |
| 📦 Examples | `ex.json` ships 3 sample patients (low / high / high risk) |

## 📊 Results

Holdout (997 patients, 20% stratified split):

| Metric | Score |
|---|---|
| ROC AUC | **0.8259** |
| Recall | **0.74** |
| Accuracy | 0.7773 |
| Precision | 0.1504 |
| F1 | 0.25 |

> ⚠️ Read these like a clinician, not a leaderboard: only ~5% of patients had strokes, so raw accuracy misleads. The model is tuned to **catch strokes (recall 0.74)** at the cost of false alarms (precision 0.15) — the correct tradeoff for screening, where a missed stroke costs far more than an extra checkup.

## ⚙️ How it works

```
brain_stroke.csv (4981 rows × 11 cols)
      ↓
5 numeric (median → scale) + 5 categorical (mode → one-hot) → stroke
      ↓
SMOTE oversampling INSIDE the pipeline (no leakage) → RandomizedSearchCV × 40 (ROC AUC)
      ↓
stroke_model_best.pkl → POST /predict { patient JSON } → { prediction, probability }
```

## 🚀 Quickstart

```bash
cd Brain-Stroke
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
python train_model.py
uvicorn app:app --reload
```

Predict (server runs at http://127.0.0.1:8000 by default):

```bash
curl -X POST http://127.0.0.1:8000/predict \
  -H "Content-Type: application/json" \
  -d "{\"gender\":\"Male\",\"age\":72,\"hypertension\":1,\"heart_disease\":1,\"ever_married\":\"Yes\",\"work_type\":\"Private\",\"residence_type\":\"Urban\",\"avg_glucose_level\":260.4,\"bmi\":35.7,\"smoking_status\":\"formerly smoked\"}"
```

Interactive docs at **http://127.0.0.1:8000/docs** 🎉

Try all three cases in `ex.json`: a healthy 25-year-old → low risk (0.004), and two high-risk seniors.

## 🛠️ Tech stack

| Layer | Tech | Why |
|---|---|---|
| Model | RandomForest + SMOTE (imblearn) | Handles 5%-positive data without drowning the minority class |
| Tuning | RandomizedSearchCV × 40, ROC AUC | Efficient search on the right metric for imbalance |
| Framework | scikit-learn | Pipelines keep preprocessing leak-proof |
| API | FastAPI + Pydantic v2 | Typed schema, auto OpenAPI docs |
| Data | pandas + joblib | CSV in, versioned pickle out |

## 📁 Project structure

```
Brain-Stroke/
├── app.py                  # FastAPI: POST /predict, GET / health check
├── train_model.py          # Training: SMOTE pipe + randomized search → pickle
├── brain_stroke.csv        # 4981 patients × 11 columns (ships with repo, 0.3 MB)
├── stroke_model_best.pkl   # Winning pipeline, regenerated by train_model.py
├── ex.json                 # 3 sample patients for quick testing
├── requirements.txt        # Python dependencies
└── README.md               # You are here 👋
```

> ⚠️ **Pickle/version note:** model pickles are tied to the scikit-learn version that made them — this one was trained on sklearn 1.9.0. Retrain with `train_model.py` if versions drift.
